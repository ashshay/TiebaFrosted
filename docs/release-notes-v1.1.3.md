# TiebaFrosted v1.1.3

这一版调整了个人页（「我的」）的整体排版，使其在顶部状态栏与底部悬浮底栏之间的可视区域内居中呈现；同时新增底栏液态玻璃样式与实时调节页，支持在 Prism 磨砂与清透液态玻璃之间切换，并独立调节磨砂程度与玻璃折射强度。

## 安装

| 文件 | 适用 |
| --- | --- |
| `TiebaFrosted-1.1.3-release.apk` | 通用包（arm64-v8a + armeabi-v7a + x86_64，56.3 MB） |

```powershell
adb install -r TiebaFrosted-1.1.3-release.apk
```

- 最低 Android 7.0（API 24），targetSdk 36
- 包名 `com.tiebafrosted.app`，可覆盖升级或与 TiebaLite 共存
- 本包使用 debug 签名，仅供测试；正式分发请自行签名

## 更新内容

### 个人页（「我的」）整体居中
- 已登录态一体化名片与「我的内容」「账号与设置」分组改为在顶部状态栏与底部悬浮底栏之间的可视区域内垂直居中，消除此前内容贴顶、下方留白过大的问题。
- 宽屏与横屏下限制内容最大宽度（560dp）并水平居中；小屏、横屏或大字号超出视口高度时保持自然滚动与下拉刷新。
- 游客态「我的」页同步在顶栏与底栏之间整体居中。
- 已有资料下拉刷新时不再在中途插入占位加载行，避免居中内容在刷新时上下跳动。

### 底栏液态玻璃样式与实时调节页
- 设置 → 外观与液态玻璃新增「底栏液态玻璃样式」入口，支持在 **Prism 磨砂** 与 **清透液态玻璃** 两种风格间切换，并在总开关关闭时提供页内快捷开启。
- 清透液态玻璃支持独立调节 **磨砂效果**（0%–100%）与 **玻璃折射**（0%–100%），内置「纯透强折射」「轻雾清透」「柔雾玻璃」三组快捷预设，上方提供可滚动高对比贴吧卡片与真实可拖拽底栏实时预览。
- 调节页路由禁用侧滑返回，避免横向拖动底栏或滑块时误触返回；主壳底栏滚动隐藏改用 `AnimatedLiquidGlassFade` 并联动选中染色。
