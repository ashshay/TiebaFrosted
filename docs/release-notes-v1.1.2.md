# TiebaFrosted v1.1.2

这一版把「看帖」这条主链路补齐了：热议榜话题里的讨论、我的帖子里的回复、消息跳转到对应楼层都能正常显示与定位；同时加了一批日常操作 —— 吧首页悬浮刷新、删帖 / 举报 / 吧务入口、个人主页的粉丝列表与一块去头图的一体化名片，并把「昵称 + @用户名」的展示方式做成可开关。

## 安装

| 文件 | 适用 |
| --- | --- |
| `TiebaFrosted-1.1.2-arm64-release.apk` | 全部主流手机（arm64-v8a） |

```powershell
adb install -r TiebaFrosted-1.1.2-arm64-release.apk
```

- 最低 Android 7.0（API 24），targetSdk 36
- 包名 `com.tiebafrosted.app`，可覆盖升级或与 TiebaLite 共存
- 本包使用 debug 签名，仅供测试；正式分发请自行签名

## 更新内容

### 热议榜 · 话题详情里的讨论能看了
- `/mo/q/newtopic/topicDetail` 把每条讨论包在 `relate_thread.thread_list[].thread_info` 里，旧代码读的是外层，标题、作者、吧名全为空，卡片只剩「贴吧用户 /（无标题）」；现在解包 `thread_info`（同时兼容老的平铺结构），补齐作者、吧名与头像、回复 / 点赞 / 分享数、时间、首楼 id。
- 讨论配图从 `media` 生成（没有时退回 `rich_abstract` 的图片节点），图片可点开看图；无标题帖用 `rich_abstract` 正文兜底。
- 翻页修正：服务端只在 `pn>1` 且带 `last_id` 时才下发第二批，`has_more` 实际在 `data.has_more`；现在带上游标并按帖子 id 去重，没有新帖就停。

### 「我的帖子 → 回复」不再空列表
- 根因：请求里带 `stoken`（proto 的 `CommonReq` 与 multipart 字段任一处）会被服务端当成「视频」页签，回一份 227 字节的空壳。现在「回复」列表两处 stoken 都不带，帖子列表保持原样（那边不带反而拿不到本人的帖）。
- 回复标题去掉「回复：」前缀，短卡片改为左对齐（此前比卡片窄的内容会被 `CardSurface` 居中）。

### 消息跳转到对应楼层
- `pb/page` 的 `pid` 只是「从这条之后开始」的游标，不是定位；现改为先用楼层接口把 pid 解析成楼层号（楼中楼消息的 pid 会解析回所属楼层），再按楼层号二分出所在页加载，渲染后把目标楼层滚进视口。
- 跳到的楼层卡片上方多一行 `⌃ 点击加载之前的楼层`，点一下补入更早的一页并把你送回那一楼；补到第 1 页后自动消失。

### 个人页：去掉头图，换成一体化名片
- 移除折叠头与头图，顶部换成一块「液态玻璃」名片：头像、昵称、`@用户名` 胶囊、吧龄、右上角编辑按钮，下面一条分隔线接四项计数（关注 / 粉丝 / 贴吧 / 帖子），宽度与下面的分组卡片对齐。
- 「我的内容」「账号与设置」分组保持不变。

### 昵称 / 用户名展示方式
- 新的展示规则：昵称单独占标题行，用户名以 `@用户名` 排到第二行最前（`@用户名 · 6楼 · 11-02 · 广东`），帖子卡片、楼层、楼中楼一致。
- 开关：设置 → 界面与外观 →「同时显示用户名与昵称」（也可在「自定义显示」里切）。

### 个人主页粉丝列表
- 新增 `/c/u/fans/page` 接口，个人主页的「关注 / 粉丝」数字变成可点（分别打开 TA 的关注 / TA 的粉丝），菜单里也补了「TA 的粉丝」；「我的」页的粉丝数直接进「我的粉丝」。

### 删帖 / 举报 / 吧务入口
- 楼层菜单：新增「举报此楼」，本人楼层可「删除我的回复」，主题楼层可「删除我的主题帖」，吧务身份额外有「吧务删除此楼 / 主题帖」。
- 帖子菜单、帖子卡片长按菜单：新增「举报帖子」，本人帖子可删除（删除后列表自动刷新）。
- 举报走 `/c/f/ueg/checkjubao` 换官方举报页，在应用内浏览器打开。
- 吧首页「⋯」菜单新增「吧务管理」，打开官方吧务后台（删帖、封禁、申诉都在里面）。

### 吧首页右下角悬浮刷新
- 46dp 圆形浮按钮，图标随刷新状态切成转圈；下拉刷新、失败重试、这个按钮共用同一条刷新路径并做了重入保护。
- 列表底部多留一个按钮高度，最后一张卡片的操作栏不会被遮住。

### 设置页赞赏码
- 设置 →「支持」→ 捐赠，弹出赞赏码（微信扫一扫），并注明「赞赏完全出于自愿，属于对作者的无偿赠予，不换取任何服务或权益」。

### 发现页「进吧」按钮
- 原来填充色与卡片底色几乎相同，看起来只有一行字；现改为全圆角胶囊 + 更亮一档的底色，明确是按钮。
