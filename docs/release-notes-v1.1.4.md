# TiebaFrosted v1.1.4

这一版把两个一直报错的功能修好了：**收藏 / 回帖**（服务端一律回「用户未登录或登录失败」）和**看别人的回复**（永远是空列表）。顺带补上 Android 预测性返回、帖子文字复制，并换了新图标。

## 安装

| 文件 | 适用 |
| --- | --- |
| `TiebaFrosted-1.1.4-release.apk` | 通用包（arm64-v8a + armeabi-v7a + x86_64，57.3 MB） |

```powershell
adb install -r TiebaFrosted-1.1.4-release.apk
```

- 最低 Android 7.0（API 24），targetSdk 36
- 包名 `com.tiebafrosted.app`，可覆盖升级或与 TiebaLite 共存
- 本包使用 debug 签名，仅供测试；正式分发请自行签名

## 更新内容

### 收藏、回帖不再报「用户未登录」

- **根因**：登录时只拿到了 BDUSS，写接口需要的 STOKEN / tbs / z_id 并不齐全；而 STOKEN 又取到了 passport 域名下的那一份，贴吧写接口并不认。浏览接口只校验 BDUSS，所以表现为「能看不能发」。
- 登录改为**只读贴吧域名**的 Cookie，等 `STOKEN` 真的种下来再完成登录，并补齐 `BAIDUZID`（即 z_id）与 `BAIDUID`；登录页会先清空旧 Cookie，避免 passport 复用已失效的令牌。
- 写操作前自动自检：缺 `tbs` 就现取，`STOKEN` 抓错就按贴吧域名纠一次；失败还会自愈重试一次，重试时丢掉帖子页带下来的旧 `tbs`。
- 仍然失败时给一条能照着做的提示，并直接提供「去登录」入口，不再把服务端原话甩给用户。
- 收藏请求额外携带 `tbs` 与 `user_id`；表单编码与 OkHttp 对齐（空格用 `%20`），`_client_id` 恒定发送。
- 账号管理页新增「能否发言」状态与「最近一次发言失败」诊断（只记录字段有无，不含凭据内容），方便反馈问题。

### 「看不到他人回复」修复

- 「回复」列表改成首屏按三种请求形状探测（默认 / 带 `stoken` / 极简），哪次拿到数据就锁定那种，翻页沿用；空页不再反复试探。
- 账号管理页会显示探测结果（`shape0=… shape1=… shape2=…`），便于确认命中哪一种。

### 预测性返回（Android 13+）

- 支持跟手预览：从左边缘滑动时当前页面跟手移动、下层页面同步前移，松手才真正返回，中途回滑可取消。
- 不受支持的机型与三键导航自动退回普通返回；`dragBack: false` 的页面（如底栏液态玻璃调节页）不接管手势，但仍可用系统返回键退出。
- **设置 → 使用习惯**新增「预测性返回手势」开关，改完即时生效。

### 复制帖子文字

- **长按任意楼层正文（含主楼）**直接弹出「复制」面板：正文可长按选中、拖两端手柄扩大范围，也可以一键「复制全部」。
- 文本规则与 TiebaLite 的 `plainText` 对齐：表情还原成 `#(名字)`、链接只留显示文字、图片 / 视频 / 语音各自单独成行占位。
- 主楼复制「标题 + 正文」，其余楼层只复制正文；楼层「…」菜单、帖子顶栏菜单、信息流卡片长按菜单与楼中楼长按都会打开同一个面板。

### 新应用图标

- 换成新的自适应图标（前景 + 背景两层）、新增圆形图标并在清单里补上 `android:roundIcon`，同时提供 Android 13+ 的 Material You 单色主题图标。
