# TiebaFrosted v1.01

围绕**图片缓存取用、操作动效手感、浏览交互与外观设置**的一次集中打磨，并包含 `v1.0.0` 之后新增的贴吧网格、经过贴吧、深链跳转与吧内等级条等改进。

## 安装

| 文件 | 适用 |
| --- | --- |
| `TiebaFrosted-1.01.apk` | 全部主流设备（arm64-v8a + x86_64） |

```powershell
adb install -r TiebaFrosted-1.01.apk
```

- 最低 Android 7.0（API 24），targetSdk 36
- 包名 `com.tiebafrosted.app`，可覆盖升级或与 TiebaLite 共存
- 本包使用 debug 签名，仅供测试；正式分发请自行签名

## 更新内容

### 缓存取用优化（减少重复载图）
- **全新二级图片缓存引擎（`TiebaImageCache` + `TiebaCachedImageProvider`）**：
  - L1 解码图缓存宽度量化到固定档位（`160 / 320 / 540 / 768 / 1080 / 1440`），同头像在不同尺寸控件间复用同一份解码纹理，且只降采样不放大；同时调优 Flutter 解码图内存上限至 `1500 张 / 160 MB`。
  - L2 进程内热字节 LRU（16 MB）+ L3 磁盘原子持久化 LRU（180 MB / 2500 文件），列表缩略图进全屏看图、重进页面与冷启动直接命中本地缓存。
  - 同 URL 并发请求合并（in-flight deduplication），并全局记住防盗链 Referer 回退状态及过滤 HTML 错误页。
- **全链路统一接入**：内联贴吧表情、保存图片到相册均接入统一缓存；「更多设置 → 清理图片缓存」实时展示磁盘缓存体积并同时清理内存与磁盘缓存。
- **保活与懒加载**：主壳 4 格 Tab 改为首次访问才挂载并保活；「动态」下推荐 / 关注 / 热榜三栏独立保活与独立滚动控制器；帖子详情、楼中楼与热榜列表全部改为 `CustomScrollView` + `SliverList.separated` 视口懒构建。

### 操作动效与手势体验
- **全屏看图器**：新增半透明淡入缩放路由，支持双击定点平滑缩放（1.0x ⇄ 2.4x）、未放大时上下拖跟手平移缩放与背景淡出关闭、相邻页自动预加载，以及缩略图升原图零闪黑切换。
- **下拉刷新**：改为局部 `ValueNotifier` + `Transform.translate` 驱动（零重建列表），加入非线性阻尼、横向手势避让、图标旋转与过阈轻震确认。
- **横滑切页**：动态页支持左右滑动切换推荐 / 关注 / 热榜（带跟手位移、边缘阻尼与方向性淡入转场）。
- **微交互与滚动流畅度**：通过 `FrostedAppBar(bindChrome: true)` 与 `Selector` 隔离滚动显隐状态，消除隐藏顶/底栏时的整页重建；骨架屏接入同步呼吸动效；补齐楼中楼点赞 `AnimatedGlyph`、单/双列切换过渡、精品分类条与表情面板展开动效，修复多指按压误释放问题。

### 浏览交互与协议增强
- 首页「关注贴吧」改为固定两列网格，并在顶部新增可折叠的「经过贴吧」横滑胶囊条。
- 吧主页折叠头收窄无图留白，在头像右侧展示吧内等级与经验进度条。
- 支持 `com.baidu.tieba://unidispatch` 协议与热启动 `onNewIntent` 深链分发；站外链接支持按设置切换内置浏览器或系统浏览器打开。
- 楼中楼预览正文调整至与楼层正文一致的字号。

### 设置与外观修复
- **使用习惯**：首组滑块改为「动态默认页」（推荐 / 关注 / 热榜），进入「动态」自动落在所选分栏；全部开关行支持整行点击切换。
- **外观与液态玻璃**：
  - 修复默认 Monet 壁纸取色下切换「配色风格（鲜明 / 微染 / 柔和 / 单色）」主色不生效的问题，并补齐风格说明与真实 Monet 预览色点。
  - 修复拖动「全局字体缩放」滑块触发全屏 `ThemeCrossFade` 卡顿的问题，新增 9 档刻度（85%–130%）与「重置 100%」快捷胶囊。
  - 调整「色相循环」定时步进至 600ms，避免打断 200ms 主题淡入动画并修复主题缓存泄漏。
  - 修复「顶栏毛玻璃模糊」整行点击无响应及选项弹窗双层嵌套滚动问题，设置变更即时同步生效。
