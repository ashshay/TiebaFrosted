# TiebaFrosted v1.1.8

这一版把**看图页的手势放大**补齐：双指缩放、双击定点放大 / 复原、放大后单指拖动、实时倍率提示，深度放大时自动换原图保证细节；同时修掉了放大态与横滑翻页、下拉关闭之间的手势冲突。

## 安装

| 文件 | 适用 |
| --- | --- |
| `TiebaFrosted-1.1.8-release.apk` | 通用包（arm64-v8a + armeabi-v7a + x86_64） |

```powershell
adb install -r TiebaFrosted-1.1.8-release.apk
```

- 最低 Android 7.0（API 24），targetSdk 36
- 包名 `com.tiebafrosted.app`，可覆盖升级或与 TiebaLite 共存
- 本包使用 debug 签名，仅供测试；正式分发请自行签名

## 更新内容

### 看图页手势放大

- **双指捏合**：`1.0× → 5.0×` 连续缩放，松手停在当前倍率；图片下方浮出实时倍率胶囊（如 `2.4×`），回到 1× 自动淡出。
- **双击定点放大**：在点击的位置放大到 `2.4×`，再双击复原；系统关闭动画时直接到位，不播过渡。
- **放大后单指拖动**：放大态下可拖到画面外的细节；捏合回到 1× 或双击复原后自动解锁翻页。
- **深度放大换原图**：倍率超过 `1.6×` 时自动把缩略图换成原图（效果等同菜单里的「查看原图」），每张图只换一次，放大的细节不再糊。
- **手势互不打架**：1× 时关闭 `InteractiveViewer` 的单指平移，横滑仍翻上 / 下一张、上下拖仍跟手关闭；双指刚落下就先锁住 `PageView`，避免第一根手指被翻页抢走。

### 修复

- 1× 时上下拖关闭被内层 `InteractiveViewer` 的单指平移吃掉：手势竞技场里它先赢，外层拿不到拖动。现在只放大后才启用平移，下拉关闭恢复。
- 缩放结束停在 `1.0×` 附近（< `1.08×`）会平滑回弹到 1×，不会留下「既没放大、又翻不了页」的中间状态。
