# TiebaFrosted v1.02

全站分段胶囊换成物理弹簧动效：滑块带速度继承、果冻拉伸与两端压墙回弹，按住胶囊还能左右拖拽跟手切换。吧主页恢复 TiebaLite 的帖子分区，`最新 ▾` / `精品` / 各个吧内分区排成吸顶滚动胶囊条，点已选中的「最新」或分区即可弹出排序菜单。

## 安装

| 文件 | 适用 |
| --- | --- |
| `TiebaFrosted-1.02.apk` | 全部主流设备（arm64-v8a + x86_64） |

```powershell
adb install -r TiebaFrosted-1.02.apk
```

- 最低 Android 7.0（API 24），targetSdk 36
- 包名 `com.tiebafrosted.app`，可覆盖升级或与 TiebaLite 共存
- 本包使用 debug 签名，仅供测试；正式分发请自行签名

## 更新内容

### 胶囊动效：从固定时长补间换成物理弹簧
- **新的分段胶囊 `FrostedSegmentedControl`**（替代 `prism_ui` 的 `AnimatedAlign + easeOutCubic`）：
  - 独立 `Ticker` 驱动的连续可打断弹簧，重设目标时继承当前瞬时速度，快速连点 / 跟手拖拽都不「刹停再拐弯」；
  - 四组弹簧分工：主位移 380ms / 0.24 回弹、跟手 1050 刚度 / 0.88 阻尼、果冻 200 刚度 / 0.48 欠阻尼、按压 220ms 膨胀；
  - 滑行时由瞬时速度驱动水平拉伸（上限 +22%）与垂直微压，切换到两端项时过冲转成「压墙压扁再弹回」，全程不越出圆角轨道；
  - 文字颜色 / 字重 / 1.02 微缩放随滑块滑过实时插值，跨格触发轻震，`disableAnimations` 时全部降为直达。
- **左右划切换**：按住胶囊横拖即跟手位移，松手按「目标位 + 速度预测」落格。
- **覆盖全部胶囊**：动态（推荐 / 关注 / 热榜）、帖子详情（正序 / 倒序 / 热门）、历史、搜索、登录、消息、TA 的帖子、编辑资料、使用习惯（2 处）、外观与液态玻璃。

### 新的可滚动胶囊条 `CapsuleTabStrip`
- 每项按文字宽度自适应，装不下时横滑滚动，并自动把选中项滚进可视区；
- 装得下时按住横拖即跟手切换，与固定胶囊同一套弹簧底座；
- 选中项可带 `▾`：**点未选中项切过去，点已选中的项弹排序菜单**（TiebaLite 原版交互）；
- 用于吧主页分区条与「热榜」分类（后者顺带补了「全部」）。

### 吧主页恢复帖子分区（TiebaLite 原版红框）
- **协议**：`frs/page` 响应补解 `nav_tab_info`（field 37）与 `FrsTabInfo.sort_menu`（field 19）；新增 `generalTabList`（`cmd=309622`）请求编码与响应解析（帖子 + 作者水合、`has_more`、`last_thread_id` 游标）。分区只取 `isGeneralTab && tabType == 15`，兼容老响应的 `frs_tab_info`。
- **界面**：原来的三格排序胶囊换成吸顶滚动胶囊条 —— `最新 ▾ | 精品 | 吧友互助 | 交流专区 | 派送专区 …`：
  - 「最新」的 `▾` 提供「按回复时间 / 按发帖时间」，选择结果写回「使用习惯 → 吧内默认排序」；
  - 「精品」保留精品分类胶囊，分类切换即时重载；
  - 每个分区独立保存列表、分页游标与滚动位置，切回来不重载；
  - 在帖子列表上左右甩也能切分区，吸顶条自动跟随。
