# TiebaFrosted v1.1.7

这一版围绕帖子详情页的评论区：新增「卡片 / 融合」两种楼层样式、补齐楼主与楼层用户的发帖所在地，并修掉楼中楼超过 30 条后加载不出更多回复的问题。

## 安装

| 文件 | 适用 |
| --- | --- |
| `TiebaFrosted-1.1.7-release.apk` | 通用包（arm64-v8a + armeabi-v7a + x86_64） |

```powershell
adb install -r TiebaFrosted-1.1.7-release.apk
```

- 最低 Android 7.0（API 24），targetSdk 36
- 包名 `com.tiebafrosted.app`，可覆盖升级或与 TiebaLite 共存
- 本包使用 debug 签名，仅供测试；正式分发请自行签名

## 更新内容

### 评论区新增「融合」样式

- 设置 → 自定义显示 → **评论区样式**，可在「卡片」与「融合」之间切换，默认保持卡片。
- 融合样式只改回复区：**主楼（首楼）正文仍是一张卡片**，卡片里的标题、正文、点赞与回复入口都不变；从第一层回复开始才铺到页面底色上。
- 融合楼层不画卡片底：头像在左、昵称加粗，正文紧跟其下；发帖时间与所在地排在正文下方，点赞挪到同一行右端（`赞 2 👍`）。
- 楼中楼不再展开预览，收进一条通栏圆角条「查看全部 N 条回复」，点进去仍是楼中楼页；首楼的回复数用评论图标排在点赞左侧。
- 楼中楼页（`N 楼的回复`）跟随同一设置切换排版：顶部被点开的普通楼层与下方回复都走融合，只有帖子首楼固定卡片；融合样式下的楼层间距也从 10dp 放宽到 18dp。

### 楼主与楼层显示发帖所在地

- 楼层的「时间 · 地区」一行补上 IP 属地（如 `11-23 · 陕西`），卡片与融合两种样式都显示；楼中楼作者接口带地区时一并显示。
- `pb/page` 有时把作者内嵌在楼层里且不带 `ip_address`，现在会用 `user_list` 里同一 uid 的资料补齐，楼主也不会漏掉地区。

### 修复楼中楼超过 30 条后无法显示更多

- **根因**：`pb/floor` 的 `page.has_more` 对楼中楼常年回 `0`，真实页数在 `total_page`（实测 2953 条回复 = 99 页）。旧逻辑只看 `has_more`，第一页 30 条之后就不再请求下一页。
- 现在同时用页码与 `total_page` 判断是否还有下一页；帖子楼层列表同样改为 `has_more || page < total_page`。
- 翻页请求至少推进到刚请求的页码，服务端回显旧页码时不会反复拉同一页。
- 下一页失败时底部出现「加载失败，点击重试」胶囊，不再无声停住；楼中楼页与楼层列表都补了「— 到底了 —」提示。
