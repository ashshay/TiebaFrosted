# TiebaFrosted v1.1.5

这一版两件事：**登录页不再被侧滑手势打断**（百度网页登录的「转动验证码」可以正常拖动），以及新增**「滚动时自动隐藏顶栏与底栏」**开关。

## 安装

| 文件 | 适用 |
| --- | --- |
| `TiebaFrosted-1.1.5-release.apk` | 通用包（arm64-v8a + armeabi-v7a + x86_64，57.3 MB） |

```powershell
adb install -r TiebaFrosted-1.1.5-release.apk
```

- 最低 Android 7.0（API 24），targetSdk 36
- 包名 `com.tiebafrosted.app`，可覆盖升级或与 TiebaLite 共存
- 本包使用 debug 签名，仅供测试；正式分发请自行签名

## 更新内容

### 登录页禁用侧滑返回

- **根因**：卡片路由的侧滑返回是「页面任意位置横拖即返回」，而登录页主体是 WebView；百度网页登录的「转动验证码」需要左右拖动拼图，一拖就被识别成返回，人被弹回上一页，验证码和整页登录进度全部丢失。
- 登录页不再接管侧滑手势，横向拖动全部交给 WebView；退出仍可用左上角返回箭头或系统返回键。
- **内置浏览器**同步改成同样处理：站内滑块、图片、地图等横向拖动不再把页面滑走。
- 验证码所需的 WebView 能力（JS、DOM storage、内置缩放）本来就是开启的，与 TiebaLite 的设置一致，无需额外配置。

### 新增「滚动时自动隐藏顶栏与底栏」开关

- 入口：**设置 → 使用习惯 → 浏览与交互**，默认开启。
- 关闭后顶栏与底部液态玻璃 Dock 常驻；**滚动途中关掉会立刻把栏放回来**，不用等下一次滚动或重进页面。
- 覆盖范围：首页、动态、消息、我的（含游客态）的顶栏 + 底栏，以及帖子详情页的顶栏与底部回复栏——这些页面共用同一套滚动收栏逻辑。
